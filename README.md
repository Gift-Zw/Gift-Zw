<h3 align="left">What I build</h3>

- **Eagle Eye** — monitoring for APIs, Windows services, servers, scheduled jobs, and SWIFT/RTGS drop folders, with SMS and email alerts
- **Notification Hub** — SMS, email, and WhatsApp with direct routing to Econet, NetOne, and Telecel
- **Pay Day Loans** — salary-day lending with a PyTorch classifier that detects salary accounts from transaction history
- **ISO Payments gateway** — REST endpoints translated to ISO 8583 for core banking transfers, balances, and mini statements
- **NSSA integration** — pension payroll API for account validation, payments, onboarding, balances, and account freeze
- **Dynamics 365 Finance and Operations** — automated exchange-rate and general-ledger posting for trial balance reporting
- Core banking integrations, including bank-to-wallet transfers, high-volume payments, and SWIFT messaging
